# 创作台当前技术栈

这份清单对应仓库里已经写上的依赖。本地演练用 `mock` 即可跑通工作流和样片；博客问答和真实模型节点需要外部接口。

## 运行环境

| 技术 | 用途 |
| --- | --- |
| Python 3.12 | gateway、identity、workflow、media、blog-rag、bookmark |
| Node.js 22 | 前端构建。开发用 Vite，生产由 Nginx 托管静态文件 |
| Docker Compose | 拉起 Postgres 和全部服务 |
| PostgreSQL 16 + pgvector | 账号、工作流、视频、书签、博客向量。LangGraph 检查点在单独的 `agent` 库 |

表在各服务启动时由 SQLAlchemy 创建，当前没有接入 Alembic。

## 前端

| 技术 | 用途 |
| --- | --- |
| React 19 + TypeScript | 页面 |
| Vite 7 | 开发服务器和打包 |
| React Router 7 | `/workflows`、`/plaza`、`/profile`、`/blog`、`/bookmarks` |
| TanStack Query | 列表读取和保存 |
| @xyflow/react | 工作流画布 |
| Tailwind CSS 4（`@tailwindcss/vite`） | 主题和样式 |
| lucide-react | 导航和节点图标 |
| 浏览器 EventSource | 工作流执行的 SSE |
| fetch 流式读取 | 博客问答。该接口是 POST，不能用 EventSource |

`clsx` 已写在 `apps/web/package.json` 里，页面代码还没有引用它。

## 后端

| 技术 | 用在哪 |
| --- | --- |
| FastAPI + Uvicorn | 全部 Python 服务 |
| httpx | 网关转发、服务之间调用、抓取网页 |
| SQLAlchemy 2（异步）+ asyncpg | 业务库 |
| Pydantic v2 / pydantic-settings | 请求体和环境变量 |
| PyJWT + bcrypt | 登录令牌和密码 |
| LangGraph | 工作流状态机、中断和恢复 |
| langgraph-checkpoint-postgres + psycopg | 把运行状态存进 Postgres |
| LiteLLM | 每个模型节点自选 OpenAI 兼容接口 |
| cryptography（Fernet） | 加密模型密钥和视频接口密钥 |
| MinIO | 成片和图标。镜像不可用时改写到服务自己的数据卷 |
| pgvector + FastEmbed（`BAAI/bge-small-zh-v1.5`） | 博客片段的向量检索 |
| feedparser | RSS 摄取 |

## 需要自己准备的外部能力

- **DeepSeek API Key**：博客问答，以及模型节点不填 `mock` 时的真实调用。
- **视频生成接口的地址和密钥**。本地演练把地址填成 `mock`。
- **GitHub Container Registry 和 Coolify**：只在推到 `main` 后自动部署时需要。本地开发不用。

MinIO 镜像能拉下来之后，用下面的命令启用：

```powershell
docker compose --profile minio -f deploy/compose.yaml up -d
```
