# 视频模型与接口接入

核对日期：2026-10-22。本文区分模型系列、接口协议和账号权限。模型名称含有“video”不代表能在本页直接使用；当前个人空间只接受文字提示词，不提供图片或视频上传。

## 当前接入范围

| 平台 / 系列 | 接入方式 | 注意事项 |
| --- | --- | --- |
| 火山方舟 / 豆包 Seedance | 原生创建任务与查询任务 | 使用模型 ID 或已开通的 `ep-` 接入点；保留控制台给出的 `/api/v3` 地址 |
| 阿里云百炼 / 万相 Wan | 原生异步视频任务 | Wan 2.6 使用 `size`，Wan 2.7 / 3.0 使用 `resolution`、`ratio`；使用控制台给出的地域、业务空间 API 地址 |
| MiniMax / 海螺、H3 | 原生 v1 / v2 视频任务 | H3 使用 v2，海螺使用 v1；v1 成功后通过 file_id 查询下载地址 |
| 快手 / 可灵 Kling | 原生文生视频任务 | 使用 `AccessKey:SecretKey` 自动签发 JWT，或自行填写有效 JWT；不把图生视频及 Omni 接口混入普通文生视频 |
| 生数 / Vidu | 原生文生视频任务 | 使用 `Token` 鉴权；Q3 Pro / Turbo 文生视频预设，排除要求图片输入的 Pro Fast / Mix |
| 爱诗 / PixVerse | 原生创建和查询视频 | 使用 `API-KEY` 与请求追踪头，处理数值状态码；模型 ID 以控制台为准 |
| 智谱 / CogVideoX | 原生生成与异步结果查询 | 接收 `video_result`，提示词限制 512 字符 |
| 腾讯云 / 混元视频 | 原生 TC3 签名接口 | `SecretId:SecretKey`，调用 `SubmitHunyuanToVideoJob` / `DescribeHunyuanToVideoJob`；默认广州地域、720p，提示词最多 200 字符 |
| xAI / Grok Imagine Video | 原生视频任务 | `request_id` 查询，支持 Grok Imagine Video 系列，排除 Grok 聊天和图片模型 |
| 硅基流动 / Wan 等视频模型 | 平台视频任务 | 从 `/models` 筛选文生视频，使用 `/video/submit`、POST `/video/status` |
| 视频中转 / 聚合服务 | 视频兼容协议 | 可选 multipart 或 JSON 提交 `/videos`，然后 GET `/videos/{id}`；按中转商实际协议选择，也可指定其采用的原生协议 |
| 自定义同步服务 | 同步 JSON 接口 | 完整生成地址接收 `prompt` / 可选 `model`，返回视频二进制或 `video_url` / `url` |

模型目录是帮助填写的预设，不是平台授权列表。没有标准列表接口的平台会明确显示“官方预设、未验证账号权限”。预设会随平台变更，支持手动输入控制台中的实际模型或资源 ID。

Google Veo、Runway、Luma 等系列在部分中转平台也提供视频服务。当前允许从返回列表识别相关文生视频模型，并通过中转商支持的视频协议调用；没有实现这些厂商各自的全部官方原生协议，也不保证任意中转商都兼容。仅有“OpenAI 兼容聊天”不能证明支持视频。

OpenAI 官方 Sora 2 和 Videos API 已于 **2026-09-24 下线**，因此禁止把 `api.openai.com` 配为生成地址。第三方服务中名称包含 `sora-` 的模型仍可作为第三方模型处理，但不代表 OpenAI 官方服务可用。

## 使用步骤

1. 打开个人空间，选择“接口类型”。官方平台可使用预填地址；中转商按其文档选择协议。阿里百炼需粘贴控制台的业务空间地址。
2. 填写地址及该平台密钥；可灵和腾讯云使用界面提示的成对凭证格式。
3. 点击“读取文生视频模型”。后台优先使用输入 / 输出模态和能力字段，再结合已知文生视频系列过滤。
4. 选择模型，或勾选手动填写，输入已开通的模型 / 接入点 ID。
5. 保存配置后生成视频。工作流中的视频节点复用同一配置及协议。

聊天、图片生成、视频理解，以及明确要求图像 / 参考视频输入的模型会被排除。模型目录没有足够能力元数据时，名称筛选不能证明账号可用；未知别名可以手动输入。读取列表不会提交收费生成任务。

## 配置兼容与运行行为

- 配置新增 `provider`，默认 `auto`；自动识别依据接口域名，不依据模型品牌。服务启动为既有 PostgreSQL 表幂等补充该列，不修改原有密钥和模型数据。
- 旧客户端仍可省略 `provider`。旧自定义 `/generate` 地址保持同步请求方式；根地址和 `/models`、完整视频提交地址会按协议归一化。
- 编辑现有配置使用 PUT，空密钥保持原值。同一用户、同一地址及同一接口类型可复用已保存的密钥读取列表；变更地址或类型需重新填密钥。
- 后台完成创建、轮询和下载后再保存作品。默认等待生成 480 秒，轮询间隔 3 秒，可通过 media 服务环境变量 `VIDEO_TIMEOUT_SECONDS`、`VIDEO_POLL_INTERVAL_SECONDS` 调整。工作流调用超时相应增加至 600 秒。
- 上游返回失败状态、HTTP 200 业务错误、缺少结果或下载非视频内容时返回明确错误，不生成空作品。连接失败或超时保留已知任务 ID，提示先到平台确认任务，避免直接重复收费。
- CDN 下载不转发平台密钥，逐跳检查重定向地址。可灵 JWT 和腾讯云 TC3 请求均在服务端构造。
- 当前仍是请求内等待生成，不含任务后台续跑、超时后自动取回、自动重试提交、多参考图输入或所有模型参数编辑。

## 契约变动

| 调用方 → 提供方 | 变动 |
| --- | --- |
| 前端 → media `/providers` | 新增平台目录，供接口类型选项和地址提示使用 |
| 前端 → media `/configs` | 请求 / 响应新增可选 `provider`，编辑复用已有配置 |
| 前端 → media `/configs/probe` | 新增可选 `provider`、`config_id`；响应新增 `source`、`filtered_count` 和说明 |
| workflow → media `/internal/generate` | 请求 / 响应不变；media 从保存配置获取协议，workflow 延长等待时间 |
| media → PostgreSQL | 新增 `video_api_configs.provider`；启动时兼容已有表 |

## 验证

后端测试需使用已安装 `services/media/requirements.txt` 依赖的 Python 3.12 环境，不需要真实 Key，也不会提交收费请求：

```powershell
cd F:\Study\ai\ai-study-cursor\services\media
python -B -m unittest discover -s tests -v
```

前端完整类型检查和生产构建：

```powershell
cd F:\Study\ai\ai-study-cursor\apps\web
npm run build
```

测试覆盖混合模型列表过滤、能力元数据、接口地址归一化、各平台提交 / 查询 / 下载、错误与超时、签名、密钥复用隔离及工作流使用保存配置。不代表真实账号的模型开通、余额、网络可达性或实际成片质量已验证。
